# Security policy

JW Calendar performs date calculations locally and does not handle account credentials or synchronize personal calendars.

Please report vulnerabilities privately through GitHub's **Report a vulnerability** feature for this repository when it is enabled. For ordinary bugs and feature requests, use [GitHub Issues](https://github.com/karencohenjw/jwcalendar-linux/issues). Do not include passwords, access tokens, or personal calendar data in public reports.

The Snap is intended to use strict confinement and only the desktop/display interfaces needed by its graphical window. The CLI and core date calculations require no network interface.
