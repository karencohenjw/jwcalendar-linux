# Changelog

## 0.1.0 — 2026-10-02

- Added `jwcalendar` CLI commands for month and year views, ISO week information, ordinal dates, Julian calendar conversion, Julian Day Number, and US federal holidays.
- Added a native GTK month and year application with date details and reference links.
- Reused the existing JW Calendar calendrical engine for strict date validation and calendar arithmetic.
- Packaged a strict-confinement Snap with a desktop launcher and Store metadata.
